# Última Marcha

Protótipo Android de roguelike de corridas automáticas feito em Godot 4.5.

A versão 0.1 traz garagem, corrida 2.5D, dois carros e seleção de cartas. É um protótipo técnico: mapa procedural, carreira de piloto e habilidades avançadas ainda não foram implementados.

No GitHub, abra **Actions → Android APK (debug)** para acompanhar a compilação e baixar o APK em **Artifacts** quando a execução for concluída com sucesso.
